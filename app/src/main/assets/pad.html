Файл игры из «Файлов» на iPhone уходит прямо на проектор. Приставка определяется по файлу: .cue + .bin, .chd, .pbp — PlayStation · .nes · .sfc · .md · .gba · .gb. Архивы .zip тоже можно, тогда спрошу, что это за приставка.

Эмуляторы ставятся внутри RetroArch: Online Updater → Core Downloader и выбери Sony - PlayStation (PCSX ReARMed), Nintendo - NES / Famicom (FCEUmm), Nintendo - SNES / SFC (Snes9x 2010), Sega - MS/GG/MD/CD (Genesis Plus GX), Nintendo - Game Boy Advance (gpSP), Nintendo - Game Boy / Color (Gambatte), Arcade (FinalBurn Neo).
